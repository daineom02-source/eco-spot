# 에코-스팟 (Eco-Spot)

인천환경공단 환경기초시설(소각시설·하수처리장) 안의 주민편익 체육시설 24곳을 한눈에 보여주는 모바일 웹앱입니다.
시설별 요금·운영 상태·예약 일정과 가까운 측정소의 실시간 대기질을 함께 보여줍니다.

2026 공공데이터 활용 앱 개발 경진대회 · 1조 (김종준, 엄다인)

---

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 앱 전체 (화면, 시설 데이터, 동작) |
| `manifest.webmanifest` | 앱 이름·아이콘 설정 (홈 화면 설치용) |
| `sw.js` | 오프라인에서도 열리게 해 주는 파일 |
| `icons/` | 앱 아이콘 |
| `data/air.json` | 실시간 대기질 (1시간마다 자동 갱신) |
| `scripts/fetch_air.py` | 에어코리아에서 대기질을 받아 오는 코드 |
| `.github/workflows/update-air.yml` | 1시간마다 위 코드를 실행하는 자동화 설정 |
| `source-data/` | 앱에 넣은 원본 정리 데이터 (CSV, 결과서 첨부용) |

## 배포 방법 (처음 한 번)

### 1. GitHub 가입
https://github.com 에서 무료로 가입합니다. 팀원 한 명이 대표로 만들고, 다른 팀원은 나중에 협업자로 초대하면 됩니다.

### 2. 저장소 만들기
1. 오른쪽 위 **+** → **New repository**
2. Repository name: `eco-spot`
3. **Public** 선택 (무료 계정은 공개 저장소만 Pages 배포 가능. 인증키는 4번에서 비밀로 넣으므로 공개돼도 안전해요)
4. **Create repository**

### 3. 파일 올리기
1. 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누릅니다.
2. 이 폴더 안의 `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`와 `icons`, `data`, `scripts`, `source-data` 폴더를 통째로 끌어다 놓습니다.
3. 아래 **Commit changes**를 누릅니다.
4. `.github` 폴더는 컴퓨터에서 숨김 폴더라 안 올라갈 수 있어요. 그럴 땐:
   - **Add file → Create new file**
   - 파일 이름 칸에 `.github/workflows/update-air.yml` 을 그대로 입력
   - 이 폴더의 `update-air.yml` 내용을 메모장으로 열어 전체 복사 → 붙여넣기 → **Commit changes**

### 4. 에어코리아 인증키 등록 (비밀)
1. 저장소 **Settings → Secrets and variables → Actions**
2. **New repository secret**
3. Name: `AIRKOREA_KEY`
4. Secret: 공공데이터포털의 일반 인증키 (Decoding 키 권장) → **Add secret**

> 인증키를 `index.html`이나 다른 파일에 직접 적지 마세요. 공개 저장소라 누구나 볼 수 있어요.

### 5. 앱 주소 만들기 (GitHub Pages)
1. **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. 예: `https://아이디.github.io/eco-spot/`

### 6. 대기질 자동 갱신 확인
1. 저장소 **Actions** 탭 → 처음이면 **I understand… enable** 버튼을 눌러 켭니다.
2. 왼쪽 **대기질 자동 갱신** → **Run workflow** → 초록 체크가 뜨면 성공
3. `data/air.json` 파일을 열어 `time`이 최근 시각인지 확인합니다.
4. 이후에는 매시 17분쯤 자동으로 갱신됩니다. (GitHub 사정으로 몇 분~수십 분 늦어질 수 있어요)

> 실패하면: 인증키가 승인 직후라 아직 반영 안 됐거나(1시간 뒤 재시도), Encoding/Decoding 키를 바꿔 넣어 보세요.
> 해외 서버에서 호출이 막히는 경우 앱은 마지막으로 저장된 값을 계속 보여줍니다.

## 폰에 설치하기

- **안드로이드 (크롬)**: 앱 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰 (사파리)**: 앱 주소 열기 → 아래 공유 버튼 → **홈 화면에 추가**

설치하면 하늘색 에코-스팟 아이콘이 생기고, 주소창 없이 앱처럼 열립니다.

## 안드로이드 설치 파일(APK) 만들기 (선택, 발표 시연용)

1. https://www.pwabuilder.com 접속
2. 5번에서 만든 앱 주소 입력 → **Start**
3. **Package For Stores → Android → Generate Package**
4. 받은 zip 안의 `.apk` 파일을 안드로이드 폰에 옮겨 설치 (출처를 알 수 없는 앱 설치 허용 필요)

## 내용 수정하는 법

시설 정보나 디자인을 바꾸면 `index.html`을 새로 받아 3번과 같은 방법으로 다시 올리면 됩니다(같은 이름이면 덮어쓰기).
1~2분 뒤 앱에 반영돼요. 이미 설치한 폰은 앱을 한 번 껐다 켜면 새 버전으로 바뀝니다.
